# TBSCI-202611

This repository provides executable binaries of the TBSCI eigensolver incorporating the FLIP algorithm, as described in the associated manuscript.
Bitstring preparation was performed using an external SCI tool as described in the manuscript.

Representative computational data for the N₂/cc-pVTZ potential energy curve are distributed via GitHub Releases.

---

## Contents

- **`bin/`** — Prebuilt executables and corresponding makefiles:
  - `Fugaku_exe.out`, `Intel_exe.out`
  - `makefile_Fugaku`, `makefile_Intel`
- **`README.md`** — This documentation.

Large computational data files are not stored in the repository and must be downloaded separately from the Releases page.

## Data availability (GitHub Releases)

The data accompanying the manuscript are distributed through [GitHub Releases](https://github.com/enhua-xu/TBSCI-202611/releases):

- **`FCI_results.tar.gz`** — Six FCI output files (`*.out`) for N₂/cc-pVTZ at bond lengths of 2.068, 2.4, 2.7, 3.0, 3.6, and 4.2 bohr. As described in the associated manuscript, the calculations were performed using the original TBSCI and FLIP implementations under different convergence criteria. The corresponding input files and the original TBSCI executable are not included.
- **`TBSCI_results.tar.gz`** — Input and output files for TBSCI calculations at the six geometries along the N₂/cc-pVTZ potential energy curve.

## File conventions

The following input-file conventions apply to the test-case directories in **`TBSCI_results/`**. The **`FCI_results/`** archive contains only the six FCI output files described above.

- **`*.FCIDUMP`**

  One- and two-electron integrals in FCIDUMP format. Core orbitals are included in the FCIDUMP files; freezing is applied at runtime via the `NFO` parameter specified in the corresponding `*.input` file.

  All FCIDUMP files are generated using PySCF. Accordingly, the character tables, irreducible representations, and their ordering follow the symmetry conventions adopted by PySCF.

- **`*.charT`**

  Character table for the point group used in the calculation. For the N₂ calculations provided here, the point group is D2h (8 irreducible representations).

- **`*.input`**

  Key parameters used in the calculations (parameter names are case-sensitive):

  - `NFO`: number of frozen core orbitals. Default: `0`.
  - `NFV`: number of frozen virtual orbitals. Default: `0`.
  - `Nirp`: number of irreducible representations (irreps) of the point group (e.g., 8 for D2h, 4 for C2v). Default: `1`.
  - `Target_irp`: target irreducible representation (symmetry sector) for the ground-state calculation. Default: `0`.
  - `Conv`: energy convergence threshold. Default: `1.0D-7`.
  - `Theta`: convergence threshold for the residual 2-norm. Default: `1.0D-4`.

- **`*.strA` and `*.strB`**

  Alpha- and beta-spin bitstrings.

  Frozen core orbitals are excluded from all bitstrings.

  The first alpha and beta bitstrings are assumed to correspond to the Hartree–Fock reference determinant.

  In `TBSCI_results/`, these files contain spin bitstrings extracted from a reference SCI wavefunction generated by DICE. The bitstrings are ranked according to their collective weights, calculated by summing the squared CI coefficients of determinants containing each bitstring. Each line consists of an integer-encoded bitstring and its associated weight.

- **`*.out`**

  In `FCI_results/`, six output files are provided for the N₂/cc-pVTZ FCI reference calculations, including the three results obtained with the earlier program version.

  In `TBSCI_results/`, output files are provided for six geometries along the N₂ potential energy curve. For these closed-shell calculations, `nAlpha = nBeta`, so only one bitstring count appears in each output filename. Using the corresponding input files and bitstring counts should reproduce results nearly identical to the provided outputs.

## How to run (typical workflow)

1. Download the data archives from the Releases page.
2. Extract the archives to obtain `FCI_results/` and `TBSCI_results/`.
3. Choose a TBSCI test-case directory, for example `TBSCI_results/N2_TZ/`.
4. Run the executable with MPI.

Example commands (Linux/HPC):

**Download the archives (release `v1.0`):**

```bash
wget https://github.com/enhua-xu/TBSCI-202611/releases/download/v1.0/FCI_results.tar.gz
wget https://github.com/enhua-xu/TBSCI-202611/releases/download/v1.0/TBSCI_results.tar.gz
```

**Extract:**

```bash
tar -xzf FCI_results.tar.gz
tar -xzf TBSCI_results.tar.gz
```

**Enter a TBSCI test-case directory:**

```bash
cd TBSCI_results/N2_TZ/
```

**Load the runtime environment** (example for Intel oneAPI; may differ by system):

```bash
source /opt/intel/oneapi/setvars.sh
```

**Run** (Intel executable example; `mpirun`/`mpiexec` depending on system):

```bash
mpirun -np <nprocs> /path/to/Intel_exe.out <prefix> <nAlpha> <nBeta> <nThreads>
```

Here:

- `<nprocs>` is the number of MPI processes to launch.
- `<prefix>` is the name of the selected test case (e.g., `N2_TZ`), used to locate the corresponding input files (`<prefix>.FCIDUMP`, `<prefix>.strA`, `<prefix>.strB`, `<prefix>.input`, and `<prefix>.charT`).
- `<nAlpha>` is the number of alpha bitstrings to include in the TBSCI calculation.
- `<nBeta>` is the number of beta bitstrings to include in the TBSCI calculation.
- `<nThreads>` is the number of OpenMP threads per MPI process.

**Notes:**

- `<nAlpha>` and `<nBeta>` must each be ≥ `<nprocs>`; otherwise, CI-vector segments cannot be distributed across MPI processes.
- `<nThreads>` must be > `1`. One OpenMP thread is dedicated to data fetching, while the remaining threads are used for computation.
- The instructions above apply to the supplied TBSCI input cases. The files in `FCI_results/` are output records, not ready-to-run test cases.

## Scope, limitations, and citation

The output files distributed through GitHub Releases were obtained on Fugaku. The supplied `Fugaku_exe.out` incorporates FLIP; as noted above, three of the FCI reference calculations were performed with an earlier program version and different convergence criteria.

`Intel_exe.out` was compiled on an internal Intel-based Linux cluster and is provided for reference; its parallel performance on other HPC systems has not been systematically evaluated.

- This repository contains executable binaries and representative data only; Fortran source code is not included.
- The `v1.0` release identifies a frozen snapshot of the executables and accompanying data.
- Future developments will be released in separate repositories.

Reduced density matrix (RDM) calculations from converged CI wavefunctions have also been implemented but are not included in the executables distributed here. Researchers interested in this functionality are welcome to contact the author to discuss potential research collaborations.
